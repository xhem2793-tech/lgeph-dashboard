# 0005. 분류기 모듈 분리 + 골든셋 회귀 테스트

- 상태: 채택됨
- 날짜: 2026-08-01

## 맥락
분류 로직(canonCode·유형·사이즈)이 1,600줄 페이지 안에 묻혀 테스트 불가 → 튜닝 시 회귀를 사람 눈으로만 확인.

## 결정
순수 분류 함수를 `src/lib/classify.ts`로 분리, `classify.test.ts`에 확정 엣지케이스(RBT=1Door·MRGB=QLED급·LG QLED가드·ISR=SxS·canonCode 병합/붕괴방지)를 골든셋으로 고정. Vitest + CI 게이트로 회귀 자동 차단.

## 결과
- 장점: 분류 정확도 회귀를 병합 전 자동 감지, 로직 재사용.
- 트레이드오프: 분류 의도 변경 시 골든셋도 함께 갱신해야(의도적 변경과 회귀를 구분하는 규율).
