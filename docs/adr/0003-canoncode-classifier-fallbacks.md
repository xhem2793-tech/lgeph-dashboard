# 0003. canonCode 병합 + 분류기 다층 폴백(기타 0%)

- 상태: 채택됨
- 날짜: 2026 (소급 기록 2026-08-01)

## 맥락
유통마다 모델 표기가 제각각(하이픈·용량토큰 혼입)이라 같은 모델이 중복 집계되고, 유형/사이즈가 미분류(기타)로 샜다.

## 결정
- **canonCode**: 모델+코드에서 측정단위 토큰(CUFT·KG·HP·L) 제외, 하이픈 결합 후 최장 영문+숫자 토큰을 병합 키로.
- **분류기 다층 폴백**: 명시 텍스트 → 브랜드 코드 프리픽스 → 사이즈 기반 최종 배정. 비제품(액세서리·의류관리기·공기청정기)은 배제. 목표는 유형 '기타' 0%.

## 대안
- 단순 코드 매칭: 표기차·용량토큰 붕괴로 오병합(예: 3.5CUFT가 병합키가 되어 서로 다른 모델이 합쳐짐).

## 결과
- 장점: 포지셔닝/보드에서 모델 1개=카드 1개, 유형 커버리지↑.
- 트레이드오프: 규칙이 복잡 → 반드시 골든셋 테스트로 보호(ADR-0005).
