# 0007. 경영기획 소유·운영(business-managed)

- 상태: 채택됨
- 날짜: 2026-08-01
- 결정자: 김성욱(경영기획)

## 맥락
법인 정식 운영을 지향하되, 소유 모델(비즈니스 관리형 vs IT 이관 vs 하이브리드)을 정해야 함.

## 결정
**경영기획이 계속 소유·운영**한다(business-managed). 제품·데이터·운영 책임을 경영기획이 보유.

## 대안
- IT 이관: 안정·감사 강하나 느리고 통제·프로세스 부담.
- 하이브리드: 현실적이나 IT 협의 필요.

## 결과
- 장점: 도메인 밀착·빠른 반복·유연성 유지.
- 트레이드오프(반드시 관리): **bus-factor 1**이 최대 리스크 → 백업 담당 지정·문서(런북/ADR/데이터사전) 최신화·자동화·정기 백업이 필수. 사내 IT 보안·DR 표준은 경영기획이 자체적으로 준수 노력.
